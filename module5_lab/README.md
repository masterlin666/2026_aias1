# Module 5 Lab

Starter files for Module 5 lab exercises.

## Setup

```bash
# Clone this repo
git clone https://course.playlab.tw/git/<your-username>/module5_lab.git
cd module5_lab

# Install required packages (inside the course Docker container)
pip install matplotlib numpy tensorboard torch torchvision transformers
```

## Lab Files

- `plot_roofline.py`
- `profile_alexnet.py`
- `profile_gpt2.py`
- `profile_resnet.py`
