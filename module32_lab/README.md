# Module 32 Lab

Starter files for Module 32 lab exercises.

## Setup

```bash
# Clone this repo
git clone https://course.playlab.tw/git/<your-username>/module32_lab.git
cd module32_lab

# Install required packages (inside the course Docker container)
pip install matplotlib numpy torch transformers
```

## Lab Files

- `lab32_1_operator_profiling.py`
- `lab32_2_roofline.py`
- `lab32_3_cost_estimator.py`
