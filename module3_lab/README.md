# Module 3 Lab

Starter files for Module 3 lab exercises.

## Setup

```bash
# Clone this repo
git clone https://course.playlab.tw/git/<your-username>/module3_lab.git
cd module3_lab

# Install required packages (inside the course Docker container)
pip install torch torchvision onnx onnxruntime
```
