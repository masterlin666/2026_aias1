# Module 13 Lab

Starter files for Module 13 lab exercises.

## Prerequisites

> **RISC-V toolchain required:** This module uses `riscv64-unknown-elf-gcc`, `riscv64-unknown-elf-as`, and `riscv64-unknown-elf-objdump`. These are pre-installed in the `acal-curriculum-workspace` Docker container. Make sure you are working inside the container.

## Setup

```bash
# Clone this repo (inside the acal-curriculum-workspace container)
git clone https://course.playlab.tw/git/<your-username>/module13_lab.git
cd module13_lab
```
